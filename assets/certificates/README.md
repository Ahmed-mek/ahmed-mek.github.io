# Certificate PDFs

All PDF files in this directory use descriptive English filenames.

The cards displayed on the website are configured in `../js/certificates-data.js`.
Edit these fields there:

- `title`: certificate name shown on the card
- `year`: year shown beside the title
- `description`: short text shown below the title
- `file`: exact PDF filename in this directory

To add another certificate, upload its PDF with an English filename and add another object to `../js/certificates-data.js`.
